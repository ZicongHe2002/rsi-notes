# 没证明显著更好，能否仍说明差异小到可以接受

“更好”“没有明显变差”和“足够接近”是三个不同主张。一次比较不能证明更好，不意味着两者相等；但若差值范围足够窄，可能支持事先约定容差内的非劣或等效结论。下面给出保守但可直接核算的配对界，不依赖正态近似。

## 从同题差值构造区间

冻结候选A、基线B和评价规则。在10000个独立同分布新任务上，每题分别记录二元正确标记，得到以下教学计数：

| 两系统结果 | 任务数 |
| --- | --- |
| A、B均正确 | 5000 |
| 只有A正确 | 1000 |
| 只有B正确 | 900 |
| 均错误 | 3100 |

A正确率60%，B正确率59%。令D_i=A_i-B_i∈[-1,1]，总体目标差值Δ=E[D_i]；样本均值为d_bar=0.01，即1个百分点。允许同一道题内A、B相关，独立假设施加在任务之间。

对宽度为2的有界独立观察，Hoeffding不等式给出

$$P(|d_{bar}-\Delta|\ge r)\le 2\exp(-nr^2/2).$$

取α=0.05，令r=√(2 ln(2/α)/n)，得到r≈0.027162，即2.7162个百分点。于是[d_bar-r,d_bar+r]≈[-1.7162,3.7162]个百分点是覆盖率至少95%的区间。该界只用到差值范围，通常较宽；10000只是本例数量，不是推荐的固定样本量。

## 事先约定什么才算可接受

| 主张 | 对总体差值的要求 | 用上述区间能否支持 |
| --- | --- | --- |
| 严格更好 | Δ>0 | 不能，区间包含0 |
| 非劣，允许最多差2个百分点 | Δ>-0.02 | 可以，整个区间下界高于-0.02 |
| 等效容差为±4个百分点 | -0.04<Δ<0.04 | 可以，整个区间位于容差内部 |
| 等效容差为±2个百分点 | -0.02<Δ<0.02 | 不能，上界超过0.02 |

这里采用同一个至少95%覆盖区间作为充分判据，因此相应错误宣称概率不超过5%；不是声称这与所有常用等效检验的临界规则或功效相同。双单侧检验等方法有自己的置信水平对应关系，不能只因名字相同就套用本表数字。

“非劣”允许A好很多，“等效”还要求其改善幅度也不超出正侧容差，二者回答不同问题。容差来自使用需求，应在看结果之前确定；不能先看到区间，再选±4个百分点去制造等效结论。上述覆盖率是重复抽样程序的性质，不是说观测后Δ有95%概率位于该区间。

题目共享模板、边测边选候选或反复查看后决定样本量，均不自动满足本区间的固定评价条件。若成本、延迟或错误严重程度也是上线要求，应单独预设其评价目标；正确率非劣不代表整体部署条件都通过。

## ±2个百分点等效要求多少样本

把样本差值固定为.01、仍用95%保守区间。严格位于$(-.02,.02)$要求同时满足$.01-r>-.02$和$.01+r<.02$，即$r<.03$且$r<.01$，由后者控制。因此纯代数门槛为$n>2\ln40/.01^2\approx73777.5891$，最小整数73778。邻点检查：$n=73777$时$r\approx.010000040$，上界超过.02；$n=73778$时$r\approx.009999972$，上界低于.02。

在这个特定中心与容差下，等效的半径门槛恰与严格改善所需$r<.01$相同。这不说明两种主张一般等价：若中心为0，可能证明容差内等效却无法证明严格改善；若中心高于.02，可能证明改善但无法落在±.02内。

二元配对结果还存在整数格点：$d_{bar}=(n_{A\ only}-n_{B\ only})/n$。若把“.01”要求为**精确观察值**，n必须为100的倍数；所以可实现这一本例精确中心的最小样本量是73800，73778只是不考虑格点的代数门槛。规划时不能保证未来样本均值恰好.01，也不能把这个固定中心计算当成给定功效的样本量设计或允许反复查看的停止规则。


练习：保持相同样本差值0.01、α=0.05，只用这条保守界，至少多少任务才能使区间下界严格大于0？答案：要求n>2 ln(40)/0.01²≈73777.59，故最小整数为73778。增加数量不修复泄漏、相关或事后选择的问题。
